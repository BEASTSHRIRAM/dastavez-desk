# Dastavez Desk

**Speak once. Review everything. Print ready.**

Voice-first document operations studio: one reusable document engine with five
professional workspaces (legal, property, government applications, travel, bookkeeping),
a LangGraph agent workflow with human approval checkpoints, and a validated
generative-UI manifest rendered by a Next.js frontend.

> Work in progress. Full setup instructions will land with the first runnable milestone.

## Layout

- `backend/` — FastAPI, LangGraph, SQLAlchemy, document rendering/export
- `frontend/` — Next.js, Tailwind, GSAP, React Three Fiber
